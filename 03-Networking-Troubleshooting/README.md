# Networking Troubleshooting Lab

## Project Overview

This project focuses on practical network troubleshooting skills commonly used in Help Desk and IT Support environments.

The exercises will cover IP configuration, connectivity testing, DNS resolution, DHCP, and basic network diagnostics.

## Lab Environment

- Virtualization: Oracle VirtualBox
- Operating System: Windows 11
- Purpose: Practice network troubleshooting in a controlled lab environment.
