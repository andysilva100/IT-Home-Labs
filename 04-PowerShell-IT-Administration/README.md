# PowerShell IT Administration Lab

## Project Overview

This project focuses on using Windows PowerShell to perform common IT administration tasks and automate basic Help Desk activities.

The exercises will demonstrate how PowerShell can be used to retrieve system information, manage users, inspect services, monitor processes, and perform routine administrative tasks.

## Lab Environment

- Virtualization: Oracle VirtualBox
- Operating System: Windows 11
- Shell: Windows PowerShell
- Purpose: Practice PowerShell commands and basic IT administration.
