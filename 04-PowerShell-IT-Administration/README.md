# PowerShell IT Administration Lab

## Project Overview

This project demonstrates the use of Windows PowerShell to perform common IT administration and Help Desk tasks.

The exercises cover system information, local user and group management, Windows services, process monitoring, disk information, network configuration, event log inspection, and basic file management.

## Lab Environment

- Virtualization: Oracle VirtualBox
- Operating System: Windows 11 Home
- Computer Name: ITLAB-WIN11
- Shell: Windows PowerShell
- Architecture: 64-bit

## Completed Exercises

1. System Information – Retrieved Windows operating system and computer information using PowerShell.
2. CPU Information – Identified processor information and virtual CPU configuration.
3. Local User Management – Listed local user accounts and checked their enabled or disabled status.
4. Local Group Management – Retrieved and filtered local Windows security groups.
5. Group Membership – Inspected membership of the local Administrators group.
6. Windows Service Management – Checked the status and startup types of DHCP, DNS, Windows Update, and BITS services.
7. Process Management – Retrieved and sorted running processes by CPU usage.
8. Disk Information – Retrieved drive letters, file systems, total capacity, and available storage.
9. Network Configuration – Inspected network adapter configuration, IP addresses, gateways, and DNS settings.
10. Event Log Inspection – Retrieved recent entries from the Windows System event log.
11. File Management – Created a directory and test file using PowerShell and verified their existence.
