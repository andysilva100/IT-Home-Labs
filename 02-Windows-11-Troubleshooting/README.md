# Windows 11 Troubleshooting Lab

## Project Overview

This project demonstrates hands-on Windows 11 troubleshooting and basic IT support tasks performed in an Oracle VirtualBox virtual machine.

The goal was to practice common Help Desk responsibilities, investigate Windows errors, monitor system performance, and manage local user accounts and permissions.

## Lab Environment

- Virtualization: Oracle VirtualBox
- Operating System: Windows 11 Home
- Environment: Virtual Machine

## Tasks Completed

### System Information and Performance

- Reviewed Windows system information using System Information ("msinfo32").
- Monitored CPU and memory usage using Task Manager.
- Reviewed running processes and resource usage.

### Windows Troubleshooting

- Investigated DHCP Client errors using Event Viewer.
- Reviewed Windows Application log errors.
- Checked DHCP Client service status and startup configuration.
- Reviewed Windows Update service status and startup configuration.
- Inspected startup applications in Task Manager.

### User Account Management

- Created a local Windows user account.
- Verified the account type.
- Confirmed the account was configured as a Standard User.
- Reviewed user permissions and account management settings.

### Disk and Storage

- Reviewed Windows storage usage and disk information through Settings.
