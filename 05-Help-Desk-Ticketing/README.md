# Help Desk Ticketing Lab

## Project Overview

This project demonstrates basic Help Desk ticket documentation and troubleshooting using GitHub Issues as a simulated ticketing system.

## Ticket Scenarios

Three simulated support tickets were created:

### 1. TICKET-001: User Unable to Sign In
   
   - Account verification and password troubleshooting.

### 2. TICKET-002: User Unable to Connect to Internet
   
   - Network configuration, connectivity testing, and DHCP troubleshooting.

### 3. TICKET-003: Computer Running Slowly
   
   - CPU, memory, startup applications, and disk space checks.

## Skills Practiced

- Ticket creation and documentation
- Issue prioritization
- Troubleshooting documentation
- Resolution tracking
- Ticket lifecycle management

## Tools Used

- GitHub Issues
- Windows 11
- PowerShell

Note: All tickets are simulated scenarios created for learning and portfolio demonstration.
